Online Shopping Data Analysis using Python and MySQL

This project demonstrates how to connect Python with a MySQL database and perform data analysis using SQL queries and Python. The project uses an online shopping database containing customer and order information. SQL queries are used to retrieve, filter, group, and analyze the data, while Python libraries such as Pandas and Matplotlib are used to process the query results and create visualizations. The project also demonstrates the use of SQL joins, aggregation, customer spending analysis, and other data analysis techniques.

Technologies Used
- Python
- MySQL
- Pandas
- Matplotlib
- MySQL Connector
- Jupyter Notebook
Key Features
- Connect Python with MySQL database
- Retrieve data using SQL queries
- Analyze customer and order data
- Use SQL JOIN, GROUP BY, SUM, AVG, COUNT, etc.
- Calculate customer spending
- Convert SQL query results into Pandas DataFrames
- Create charts using Matplotlib
- Perform customer and product-related analysis
